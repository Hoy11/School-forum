# 帖子模块文档

## 1. 模块字段设计

### 1.1 帖子表(post)

| 字段名 | 数据类型 | 长度 | 允许空 | 主键 | 说明 |
| --- | --- | --- | --- | --- | --- |
| post_id | int | 11 | 否 | 是 | 帖子ID，自增主键 |
| user_id | int | 11 | 否 | 否 | 发帖用户ID，关联用户表 |
| section_id | int | 11 | 否 | 否 | 所属版区ID，关联版区表 |
| title | varchar | 200 | 否 | 否 | 帖子标题 |
| content | text | - | 否 | 否 | 帖子内容，支持HTML富文本格式 |
| create_time | datetime | - | 否 | 否 | 发布时间，系统自动生成 |
| update_time | datetime | - | 是 | 否 | 最后更新时间，编辑时更新 |
| view_count | int | 11 | 否 | 否 | 浏览次数，默认为0 |
| is_essence | int | 1 | 否 | 否 | 是否精华（0-否，1-是），默认为0 |
| status | int | 1 | 否 | 否 | 帖子状态（0-删除，1-正常），默认为1 |

### 1.2 帖子收藏表(post_favorite)

| 字段名 | 数据类型 | 长度 | 允许空 | 主键 | 说明 |
| --- | --- | --- | --- | --- | --- |
| id | int | 11 | 否 | 是 | 收藏ID，自增主键 |
| post_id | int | 11 | 否 | 否 | 帖子ID，关联帖子表 |
| user_id | int | 11 | 否 | 否 | 用户ID，关联用户表 |
| create_time | datetime | - | 否 | 否 | 收藏时间，每次操作更新 |
| status | int | 1 | 否 | 否 | 状态（0-取消收藏，1-已收藏） |

### 1.3 帖子实体类定义

帖子实体(Post.java)核心属性:
- id：帖子唯一标识符，使用@TableId注解标识主键且自增
- userId：帖子作者ID，外键关联用户表
- sectionId：所属版区ID，外键关联版区表
- title：帖子标题，限制2-200字符
- content：帖子内容，支持富文本格式，存储HTML内容
- createTime：创建时间，创建时自动设置
- updateTime：更新时间，编辑时自动更新
- viewCount：浏览次数，默认为0，每次访问累加
- isEssence：是否精华，用于内容质量标记
- status：帖子状态，控制帖子可见性
- 非数据库字段：
  - username：用户名（联查用户表得到）
  - sectionName：版区名称（联查版区表得到）
  - authorAvatar：作者头像（联查用户表得到）
  - commentCount：评论数量（统计评论表得到）
  - favoriteCount：收藏数量（统计收藏表得到）
  - isFavorited：当前用户是否收藏（查询收藏表得到）
  - user：用户完整信息（对象关联）
  - section：版区完整信息（对象关联）

帖子收藏实体(PostFavorite.java)核心属性:
- id：收藏记录ID，主键自增
- postId：帖子ID，外键关联帖子表
- userId：用户ID，外键关联用户表
- createTime：收藏时间，记录操作时间
- status：收藏状态，控制收藏有效性
- 非数据库字段：
  - postTitle：帖子标题（联查帖子表得到）
  - isFavorite：是否已收藏（布尔值转换）

## 2. 帖子发布功能

帖子发布功能允许用户在指定版区创建新帖子，支持富文本编辑和图片上传，是论坛系统核心交互功能之一。

### 2.1 功能流程与说明

1. **用户选择版区** - 用户在版区列表或版区详情页点击"发表帖子"按钮，系统自动记录当前版区ID
2. **填写帖子内容** - 用户填写帖子标题和正文内容，富文本编辑器支持文本格式化、插入图片等功能
3. **内容校验** - 前端进行内容有效性校验，确保标题和内容符合要求
4. **提交帖子** - 用户点击"发表帖子"按钮，系统将帖子信息提交到后端
5. **权限验证** - 后端验证用户登录状态和发帖权限
6. **数据处理** - 后端对数据进行安全处理和格式化，包括XSS防护
7. **入库存储** - 系统将帖子信息存入数据库，并返回成功结果
8. **页面跳转** - 发布成功后，系统自动跳转到帖子详情页或版区页面

### 2.2 权限控制

1. **登录验证** - 只有登录用户才能发表帖子，通过JWT token验证
2. **版区状态** - 只能在正常状态(status=1)的版区发帖，禁用版区不允许发帖
3. **用户状态** - 只有正常状态(status=1)的用户才能发帖，被禁用用户无法发帖
4. **内容审核** - 对标题和内容进行基础敏感词过滤，防止恶意内容

### 2.3 实现细节

#### 2.3.1 后端实现

功能实现流程:
【PostController.java: createPost】接收前端POST请求，从token中解析用户ID，验证权限后调用帖子服务创建帖子。具体步骤:
1. 从请求头或参数中获取token并验证有效性
2. 解析token获取用户ID，建立用户上下文
3. 验证请求参数的有效性和完整性
4. 调用PostService.createPost方法处理业务逻辑
5. 返回统一格式的响应结果

【PostService.java: createPost】验证用户和版区存在性，创建Post对象设置初始属性，调用Mapper插入数据库。具体步骤:
1. 通过userService.getUserById验证用户是否存在且状态正常
2. 通过sectionService.getSectionById验证版区是否存在且状态正常
3. 创建Post实体对象，并设置必要属性
4. 设置默认值：创建时间、浏览量(0)、默认状态等
5. 调用postMapper.insert执行数据库插入操作
6. 如插入失败，抛出ServiceException异常

【PostMapper.java: insert】执行SQL插入操作，将帖子数据持久化到数据库。
MyBatis-Plus执行类似如下SQL:
```sql
INSERT INTO post (user_id, section_id, title, content, create_time, view_count, is_essence, status)
VALUES (?, ?, ?, ?, ?, ?, ?, ?)
```

```java
// PostService.java: createPost方法
public void createPost(PostDTO postDTO, Long userId) {
    // 验证用户和版区存在性
    User user = userService.getUserById(userId);
    if (user.getStatus() != 1) {
        throw new ServiceException("账号已禁用，无法发布内容");
    }
    
    Section section = sectionService.getSectionById(postDTO.getSectionId());
    if (section.getStatus() != 1) {
        throw new ServiceException("该版区已禁用，无法发布内容");
    }
    
    // 创建帖子对象
    Post post = new Post();
    post.setUserId(userId);
    post.setSectionId(postDTO.getSectionId());
    post.setTitle(postDTO.getTitle());
    post.setContent(postDTO.getContent());
    post.setCreateTime(new Date());
    post.setViewCount(0);
    post.setIsEssence(postDTO.getIsEssence() != null ? postDTO.getIsEssence() : 0);
    post.setStatus(postDTO.getStatus() != null ? postDTO.getStatus() : 1);
    
    // 基础内容安全过滤
    if (containsSensitiveWords(post.getTitle()) || containsSensitiveWords(post.getContent())) {
        throw new ServiceException("内容包含敏感词，请修改后重试");
    }
    
    if (postMapper.insert(post) <= 0) {
        throw new ServiceException("帖子创建失败");
    }
    
    // 更新版区帖子计数（可选实现）
    // sectionService.incrementPostCount(postDTO.getSectionId());
}

// 敏感词检测方法（示例）
private boolean containsSensitiveWords(String content) {
    // 实际项目中可能使用更复杂的敏感词过滤算法或第三方服务
    List<String> sensitiveWords = Arrays.asList("违禁词1", "违禁词2", "违禁词3");
    for (String word : sensitiveWords) {
        if (content.contains(word)) {
            return true;
        }
    }
    return false;
}
```

## 3. 帖子详情与浏览功能

帖子详情功能展示帖子的完整内容、作者信息、评论列表等，并提供交互功能如收藏、举报等。每次访问会增加帖子浏览量，是用户获取内容和进行互动的核心界面。

### 3.1 功能流程与说明

1. **获取帖子数据** - 前端根据URL中的帖子ID请求帖子详情
2. **增加浏览计数** - 系统自动为该帖子增加浏览次数
3. **检查收藏状态** - 如用户已登录，获取该用户对该帖子的收藏状态
4. **获取评论列表** - 加载该帖子的评论树结构
5. **页面渲染** - 渲染帖子内容、作者信息、统计数据和评论区
6. **用户交互处理** - 处理用户的收藏、评论、举报、删除等操作

### 3.2 权限控制

1. **查看权限** - 所有用户(包括未登录用户)均可查看正常状态的帖子
2. **收藏权限** - 仅登录用户可收藏帖子
3. **评论权限** - 仅登录用户可发表评论和回复
4. **举报权限** - 登录用户可举报帖子，但不能举报自己的帖子
5. **编辑/删除权限** - 仅帖子作者、版主或管理员可编辑和删除帖子

### 3.3 实现细节

#### 3.3.1 后端实现

功能实现流程:
【PostController.java: getPostById】接收前端GET请求，处理帖子详情获取逻辑。具体步骤:
1. 接收路径参数中的帖子ID
2. 尝试从请求头中获取token，解析用户ID(未登录用户则userId为null)
3. 调用PostService.getPostDetailById获取帖子详情，传入帖子ID和用户ID(可选)
4. 返回统一格式的成功响应，包含帖子详情数据

【PostService.java: getPostDetailById】查询帖子详细信息并填充关联数据。具体步骤:
1. 调用getPostById获取帖子基本信息
2. 调用fillUserAndSectionInfo填充用户和版区信息
3. 如果userId不为null(已登录)，查询用户是否已收藏该帖子
4. 查询帖子收藏数量并设置到返回对象中
5. 返回完整的帖子详情对象

【PostController.java: incrementViewCount】增加帖子浏览次数，单独实现为避免频繁更新影响性能。具体步骤:
1. 接收路径参数中的帖子ID
2. 调用PostService.incrementViewCount增加浏览次数
3. 返回统一格式的成功响应

【PostService.java: incrementViewCount】实现浏览计数更新逻辑。具体步骤:
1. 根据ID查询帖子是否存在
2. 如果存在，浏览次数+1
3. 更新数据库中的帖子记录

关键SQL查询(通过MyBatis-Plus实现):
```sql
-- 查询帖子详情
SELECT p.*, u.username, u.avatar, s.section_name
FROM post p
LEFT JOIN user u ON p.user_id = u.user_id
LEFT JOIN section s ON p.section_id = s.section_id
WHERE p.post_id = #{id}

-- 更新浏览次数
UPDATE post SET view_count = view_count + 1 WHERE post_id = #{id}
```

### 3.4 评论区实现

```
public boolean toggleFavorite(Long postId, Long userId) {
    // 验证用户和帖子存在性
    User user = userService.getUserById(userId);
    Post post = postService.getPostById(postId);
    
    // 查询收藏记录

    if (favorite == null) {
        // 不存在收藏记录，创建新记录

        favorite.setPostId(postId);
        favorite.setUserId(userId);
        favorite.setCreateTime(new Date());
        favorite.setStatus(1); // 已收藏
        
        if (postFavoriteMapper.insert(favorite) <= 0) {
            throw new ServiceException("收藏操作失败");
        }
        isNowFavorite = true;
    } else {
        // 存在记录，切换状态
        int newStatus = favorite.getStatus() == 1 ? 0 : 1;
        favorite.setStatus(newStatus);
        favorite.setCreateTime(new Date()); // 更新时间
        
        if (postFavoriteMapper.updateById(favorite) <= 0) {
            throw new ServiceException("更新收藏状态失败");
        }
        isNowFavorite = newStatus == 1;
    }
    
    return isNowFavorite;
}
```

```
public Map<String, Object> getSectionPostStats(Long sectionId) {
    // 构建查询条件
    LambdaQueryWrapper<Post> queryWrapper = new LambdaQueryWrapper<>();
    queryWrapper.eq(Post::getSectionId, sectionId)
                .eq(Post::getStatus, 1); // 只统计正常状态的帖子

    // 获取总帖子数
    long totalPosts = postMapper.selectCount(queryWrapper);

    // 获取今日新增帖子数
    Calendar calendar = Calendar.getInstance();
    calendar.set(Calendar.HOUR_OF_DAY, 0);
    calendar.set(Calendar.MINUTE, 0);
    calendar.set(Calendar.SECOND, 0);
    calendar.set(Calendar.MILLISECOND, 0);
    Date todayStart = calendar.getTime();

    queryWrapper.ge(Post::getCreateTime, todayStart);
    long todayPosts = postMapper.selectCount(queryWrapper);

    Map<String, Object> stats = new HashMap<>();
    stats.put("totalPosts", totalPosts);
    stats.put("todayPosts", todayPosts);

    return stats;
}
```

## 7. 热门帖子功能

热门帖子功能按照浏览量排序展示帖子，帮助用户快速发现热门内容。

功能实现流程:
【PostController.java: getHotPosts】接收前端请求，调用服务层获取热门帖子。
【PostService.java: getPostByViewCount】获取所有帖子并按浏览量降序排序。

前端实现:
【SectionDetail.vue】在版区详情页提供热门排序功能，点击"最热"选项触发热门帖子查询API，结果以列表形式展示。

关键代码示例:
```
// PostService.java: getPostByViewCount方法
public Page<Post> getPostByViewCount() {
    Page<Post> page = new Page<>(1, Integer.MAX_VALUE);
    Page<Post> postPage = postMapper.selectPostPage(page, null, null, null, null, null);
    List<Post> records = postPage.getRecords();
    records.sort((o1, o2) -> o2.getViewCount().compareTo(o1.getViewCount()));
    records.forEach(this::fillUserAndSectionInfo);
    postPage.setRecords(records);
    return postPage;
}
```

```
// PostService.java: fillUserAndSectionInfo方法
private void fillUserAndSectionInfo(Post post) {
```
