举报模块功能文档

一、模块字段设计

1.1 举报表(Report)字段设计
id：整型，主键，举报ID，自增
user_id：整型，外键，关联用户表，举报用户ID
type：整型，举报类型(1-帖子，2-评论，3-资源)
target_id：整型，外键，举报目标ID(根据type关联不同表)
reason：字符串型，举报原因
create_time：日期时间型，举报时间
handler_id：整型，外键，关联用户表，处理人ID
handle_time：日期时间型，处理时间
status：整型，举报状态(0-未处理，1-已处理，2-驳回)

1.2 实体类定义

【Report.java】
实体类包含举报表的基本字段，以及以下扩展字段：
username：字符串，举报用户名（非数据库字段）
handlerName：字符串，处理人用户名（非数据库字段）
targetContent：字符串，目标内容摘要（非数据库字段）

1.3 数据传输对象定义

【ReportDTO.java】
type：Integer类型，举报类型(1-帖子，2-评论，3-资源)，必填
targetId：Long类型，举报目标ID，必填
reason：String类型，举报原因，必填

@PostMapping("/add")
@Operation(summary = "创建举报", description = "创建新的举报")
public Result createReport(@RequestBody @Valid ReportDTO reportDTO, HttpServletRequest request) {
    // 从请求头中获取token并解析用户ID
    String token = request.getHeader("token");
    if (StringUtils.isBlank(token)) {
        token = request.getParameter("token");
    }
    if (StringUtils.isBlank(token)) {
        return Result.error("未授权，请先登录");
    }
    
    Long userId;
    try {
        String userIdStr = JWT.decode(token).getAudience().get(0);
        userId = Long.valueOf(userIdStr);
    } catch (Exception e) {
        return Result.error("token无效或已过期");
    }
    
    reportService.createReport(reportDTO, userId);
    return Result.success("举报提交成功");
}

【ReportService.java：创建举报方法】
createReport方法进行必要的验证并创建举报记录:
public void createReport(ReportDTO reportDTO, Long userId) {
    // 验证用户是否存在
    userService.getUserById(userId);
    
    // 验证举报类型是否合法
    if (reportDTO.getType() < 1 || reportDTO.getType() > 3) {
        throw new ServiceException("举报类型不合法");
    }
    
    // 检查目标是否存在
    checkTargetExists(reportDTO.getType(), reportDTO.getTargetId());
    
    // 创建举报对象
    Report report = new Report();
    report.setUserId(userId);
    report.setType(reportDTO.getType());
    report.setTargetId(reportDTO.getTargetId());
    report.setReason(reportDTO.getReason());
    report.setCreateTime(new Date());
    report.setStatus(0); // 默认状态为未处理
    
    if (reportMapper.insert(report) <= 0) {
        throw new ServiceException("举报创建失败");
    }
}

public void handleReport(Long id, Integer status, Long handlerId) {
    // 验证举报是否存在
    Report report = getReportById(id);
    
    // 验证处理人是否存在
    userService.getUserById(handlerId);
    
    // 验证状态是否合法
    if (status != 1 && status != 2) {
        throw new ServiceException("处理状态不合法");
    }
    
    // 如果是处理（而非驳回），则下架对应的目标
    if (status == 1) {
        takeDownReportTarget(report);
    }
    
    // 更新举报状态
    Report updateReport = new Report();
    updateReport.setId(id);
    updateReport.setStatus(status);
    updateReport.setHandlerId(handlerId);
    updateReport.setHandleTime(new Date());
    
    if (reportMapper.updateById(updateReport) <= 0) {
        throw new ServiceException("举报处理失败");
    }
}

3.4 内容下架功能

3.4.1 实现流程
1) 管理员处理举报时自动触发内容下架
2) 根据举报类型调用不同服务的下架方法
3) 更新被举报内容状态为删除

【ReportService.java：下架目标方法】
takeDownReportTarget方法根据举报类型下架不同内容:
private void takeDownReportTarget(Report report) {
    Integer type = report.getType();
    Long targetId = report.getTargetId();
    
    switch (type) {
        case 1: // 帖子
            postService.updatePostStatus(targetId, 0); // 将帖子状态设为删除
            break;
        case 2: // 评论
            commentService.updateCommentStatus(targetId, 0); // 将评论状态设为删除
            break;
        case 3: // 资源
            // 假设资源服务中也有类似的方法
            resourceService.updateResourceStatus(targetId, 0);
            break;
        default:
            throw new ServiceException("举报类型不合法");
    }
}

举报模块是师生交流论坛系统的重要组成部分，提供了对不良内容的及时处理机制。用户可以举报帖子、评论和资源中的不适当内容，管理员可以高效地查看和处理举报信息，对违规内容进行下架处理，确保系统内容的健康有序。举报处理流程设计合理，既支持对违规内容的处理，也提供了对误举报的驳回机制，平衡了内容管理的效率和公正性。
